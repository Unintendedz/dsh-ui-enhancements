# dsh-ui-enhancements

[English](./README.md) | 中文

为 DeepSeek Harness 提供独立、克制的小型界面增强。

## 当前功能

### 配置档插件开关

打开 **设置 → 插件 → 插件列表**，即可启用或停用当前 DSH 配置档中安装的每个插件包。

- 修改会立即应用到 Host Loader，并在 DSH 重启后继续生效。刷新页面可同步浏览器插件：开关成功后会显示明确提示和刷新按钮，提醒先保存未发送的内容；插件不会自动刷新。
- 选择结果保存在该配置档 `cordis.patch.yml` 的托管区块中，保留其他设置和注释。支持行内和块状序列（行内格式可能转换为块状格式）；非法 YAML 或补丁条目会在原子替换文件前被拒绝。
- `dsh-ui-enhancements` 自身的开关保持可见但锁定为启用，避免恢复入口停用自己。
- DSH 内置运行组件仍然只读，因为停用核心服务可能导致 Web 界面或插件管理器不可用。
- 如果运行时更新失败，插件会恢复原有持久化状态，开关仍可重试。

`0.3.0` 版本需要 DSH `0.1.5-rc.1` 及其 JSONL 会话存储后端。安装后请重启 DSH，以便插件跟踪每个对话的原生生命周期。

### 会话快捷操作

悬停已有内容的会话行时，在原生菜单旁直接显示 **置顶/取消置顶**、**归档** 和 **立即删除**。

- 置顶会话保持在当前工作区分组或单列表顶部。
- Pin 偏好只保存在当前浏览器的本地存储中。
- 归档沿用 DSH 原生的非破坏性归档操作。
- 立即删除会弹出一次确认，默认聚焦 **取消**。确认后停止这个对话，删除它的所有 JSONL 日志版本、工作区记录、归档记录和搜索记录，并刷新侧栏。操作失败会显示错误，允许重试。
- 删除仅针对这个会话，保留工作区文件、独立分支和共享附件文件。日志不会移入回收站，删除无法撤销。
- 运行中会话更新状态时，hover 按钮仍保持稳定。
- 键盘焦点和触屏设备同样可以访问这些操作。

### 已归档对话

点击侧栏底部、**设置** 上方的 **已归档**。即使普通会话列表为空，也能找到这个入口。

- 按归档标题或工作区路径搜索，包括 DSH 之前运行时归档的对话。
- **查看** 提供用户和助手消息的只读文本预览，对话仍保持归档。恢复后可查看完整对话，包括工具和附件。
- **恢复并打开** 会取消归档，保留原工作区归属，并打开对话。
- 这里同样提供 **立即删除**，使用与普通列表相同的确认流程。
- 列表读取 Host 的真实归档记录，不会把仅由 `dsh-conversation-tree` 折叠隐藏的版本当成已归档。

本插件不添加 Agent 工具。归档列表读取标题和元数据，只有点击 **查看** 才会读取消息文本，不会创建对话副本。

### 兼容性

DSH `0.1.5-rc.1` 没有原生的恢复和删除接口。本版本复用其工作区串行写入、Agent 原生生命周期句柄、JSONL 写锁及 SQLite 搜索清理。升级 DSH 前需要重新验证这些集成。如果某个会话在插件加载前已经启动，请重启 DSH。由其他 Agent 管理的子代理会话不能直接删除。

## 安装

```sh
dsh plugin --profile web add github:Unintendedz/dsh-ui-enhancements#v0.3.0
```

安装或卸载后请重启 DSH Web 服务。

## 卸载

```sh
dsh plugin --profile web remove dsh-ui-enhancements
```

## 开发

```sh
npm install
npm test
```
